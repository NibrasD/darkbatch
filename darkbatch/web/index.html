DarkBatch: Technical Whitepaper & Architectural Summary

DarkBatch brings the venture-backed market structure innovation of Archer Exchange (4th Place DeFi in Colosseum Cypherpunk) directly to Zcash NU6.3 (Ironwood Era).

1. Zero-Leak Sealed Intent Protocol

Unlike transparent order books where high-frequency bots front-run and extract MEV, DarkBatch uses a sealed mempool where only Pallas Pedersen value commitments ($C = [v]\mathcal{V} + [r]\mathcal{R}$) are visible. Trade prices, sizes, and counterparties are 100% concealed.

2. Authentic ZIP-228 Swap Bundles

Each Swap Order forms an ActionGroup containing both a SwapAction and a FeeAction. The binding keys are summed up ($bsk_{\text{bundle}} = \sum bsk_i \pmod q$), proving that the bundle conserves value on-chain without disclosing individual amounts.

3. Strict 512-Byte Memos & ZIP 229 (Transaction v6)

Settlement transactions conform to ZIP 229 (Transaction v6) with mandatory consensus Version Group ID 0xD884B698, authentic 820-byte OrchardAction encodings (§ 7.5), 580-byte encCiphertext (lead byte 0x03 for Ironwood), and live Testnet broadcast adapter integration.
